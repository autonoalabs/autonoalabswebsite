# AUTONOA LABS Website

Conversion-focused static website for AUTONOA LABS.

## Current build
- Hook-first animated hero showing manual work becoming automated.
- Six example cards removed; the site now reinforces the process-first positioning.
- Shorter navigation and stronger enquiry CTAs.
- Enquiry form posts to the existing Google Apps Script endpoint.
- Client-side validation for name, email, phone and process description.
- Character counter, inline validation, loading state, success state and a hidden honeypot field.
- Existing AUTONOA LABS logo and SEO files retained.

## Deployment
Upload the contents of this folder to the existing Cloudflare Worker/static deployment using the same method as the current site.
